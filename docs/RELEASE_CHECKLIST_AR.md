# قائمة مراجعة الإصدار — Shbeeb One 0.12.0

**الحالة:** حزمة اختبار Android، versionCode `19`، package `com.shbeeb.ai`. النجاح الآلي لا يثبت تشغيل النماذج أو سلامة الحرارة والأداء على OPPO Find X5؛ لم يكن هاتف فعلي موصولاً بهذه البيئة.

- [x] اجتياز `yarn typecheck`.
- [x] اجتياز `yarn lint`: صفر أخطاء و88 تحذيراً قائماً في المصدر، معظمها تحذيرات أسماء متداخلة واستيرادات RN داخلية.
- [x] اجتياز `:app:testDebugUnitTest` بعد إضافة اختبارات لنسخ LiteRT الآمن.
- [x] نجاح `:app:assembleDebug` و`:app:assembleRelease` للإصدار 0.12.0 بعد آخر تعديل لدليل العربية.
- [x] نجاح `:app:lintDebug`.
- [x] التحقق من إصدار APK بواسطة `aapt`: `0.12.0`، versionCode `19`، Android package `com.shbeeb.ai`.
- [x] التحقق من توقيع APK بواسطة `apksigner`: توقيع APK Scheme v2 صالح، بموقّع واحد.
- [x] احتواء APK على `assets/index.android.bundle` ومكتبة `lib/arm64-v8a/libshbeeb_media.so`.
- [x] `git diff --check` بلا أخطاء تنسيق whitespace.
- [ ] التحقق من GitHub Actions وartifact/ZIP العام للـcommit الجديد؛ نتيجة CI لم تُفحص بعد.
- [x] إصدار الاختبار `0.12.0`، versionCode `19`؛ الحزمة موقعة بمفتاح Debug للاختبار وليست مفتاح نشر تجاري.

## 2. ما الذي تغيّر في الواجهة

- استُبدلت نقطة دخول Compose القديمة بواجهة عربية جديدة تفتح مباشرة على المساعد، مع شريط تنقل للاستوديو والأدوات والإعدادات.
- توحدت الألوان الفاتحة والخطوط والبطاقات في الواجهات الأصلية، وصُححت شاشة الصوت ودليل الاستخدام لعدم وصفها كمحادثة ثنائية الاتجاه.
- كل إرسال إلى مزود محادثة سحابي يطلب موافقة المستخدم ويشير إلى احتمال استهلاك رصيد أو رسم.
- صفحة AnythingLLM ما زالت في الشفرة، لكن فتحها مخفي مؤقتاً لأن دخول React Native كان يغلق التطبيق؛ أضيف تسجيل محلي للأخطاء، لكن السبب الجذري لم يُثبت دون سجل جهاز.

## 3. ما يجب اختباره على OPPO Find X5

| المجال | خطوات القبول | ملاحظات واقعية |
| --- | --- | --- |
| التثبيت والواجهة | تثبيت APK، فتح المساعد، التنقل بالعربية، فحص شريط الحالة ولوحة المفاتيح | حزمة Release تجريبية؛ قد يتطلب التحديث إزالة نسخة موقعة بمفتاح مختلف بعد حفظ البيانات |
| LiteRT-LM | اختيار ملف محلي `.litertlm`، بدء محادثة فعلياً، ثم التجربة دون إنترنت | ينشئ التطبيق نسخة تشغيل داخلية بامتداد صحيح؛ يلزم حجم إضافي قريب من حجم النموذج + 128 MB. يبقى المصدر المشترك كما هو |
| السحابة | إعداد مفتاح، قراءة تنبيه الموافقة لكل رسالة، ثم اختبار مزود واحد | افحص بيانات الحساب والتكلفة بنفسك؛ لا يُرسل الطلب قبل الموافقة في الواجهة الجديدة |
| الصوت | سؤال واحد، انتظار تحويله إلى نص، سماع الرد، ثم إيقاف الجلسة | دورات متتابعة وليست استماعاً دائماً؛ Android STT قد يحتاج الإنترنت أو حزمة لغة |
| الصور المحلية | توفير نموذج SD 1.5 Q4 (نحو 1.57 GB)، التوليد 512×512، الإلغاء، حفظ PNG | النموذج غير مرفق. سجّل الزمن وRAM والحرارة؛ لم يُختبر بعد على الهاتف |
| الفيديو | اختيار صورة وإنشاء/تشغيل MP4 | فيديو صامت عمودي مدته 8 ثوانٍ من صورة؛ ليس توليد فيديو ذكاء اصطناعي |
| الملفات والمهام | معاينة نص محلي وإضافة/حذف مهمة | معاينة الملفات محدودة ولا تُرفع تلقائياً؛ المهام لا تعمل في الخلفية |
| التحكم الآمن | تجربة فتح إعداد أو لوحة اتصال/مشاركة | Intent بعد تأكيد؛ لا ينفّذ التطبيق مكالمة أو مشاركة خفية |
| AnythingLLM وGGUF | لا تختبر في هذه النسخة؛ الواجهة مخفية حتى تشخيص عطل البدء | سجلات التشخيص محلية؛ راجع Logcat وامسح أي محتوى خاص قبل مشاركته |

## 4. الخصوصية والتراخيص

- مفاتيح API تُحفظ مشفرة عبر Android Keystore. السجل المحلي للمحادثات اختياري ومغلق افتراضياً وغير مشفر تشفيراً خاصاً.
- لا يُرفع Telemetry أو تقرير Crashlytics؛ أخطاء بدء React Native تسجّل محلياً في Android Logcat.
- لا تُرفق أوزان Gemma أو Stable Diffusion مع APK؛ يختار المستخدم الملف وموقعه. أوزان النماذج لها تراخيص منفصلة عن شفرة التطبيق.
- المشروع المركب يتضمن AnythingLLM المرخص بـGPL-3.0-or-later ومكونات أخرى؛ راجع `LICENSE` و`THIRD_PARTY_NOTICES.md`.
- التوقيع الحالي Debug للتجربة فقط؛ يلزم توقيع إنتاجي، مراجعة أمان، وتجربة هاتف قبل نشر تجاري.
