# قائمة مراجعة شاملة — مصنع الذكاء شبيب 0.10.0

> هذه قائمة قبول لا شهادة إطلاق. كل ما لم يُفحص على هاتف OPPO Find X5 في الجدول أدناه يبقى «ينتظر الاختبار». لا تُدمج التعديلات إلى main دون موافقة صاحب المشروع.

## 1. منهج الفحص من طرف التطوير
- [ ] GitHub Actions يجري `testDebugUnitTest` بنجاح على SHA آخر تعديل.
- [ ] GitHub Actions يجري `lintDebug` بنجاح.
- [ ] GitHub Actions يجري `assembleDebug` بنجاح ويرفع artifact `shbeeb-ai-debug-apk`.
- [ ] التأكد أن رقم الإصدار الظاهر بالتطبيق `0.10.0` يطابق Gradle.
- [ ] فحص عدم وجود أسرار مضمّنة في GitHub أو APK. مفاتيح مزودي الخدمات في ذاكرة جلسة التطبيق فقط.
- [ ] مراجعة الأذونات: إنترنت فقط، والاستماع الصوتي عبر خدمة Android بطلب المستخدم، والملفات عبر منتقي النظام.

## 2. اختبار الهاتف خطوة بخطوة — عند عودة المستخدم
1. **التثبيت:** إذا ظهر تعارض توقيع، لا تحذف بيانات التطبيق قبل حفظ أي سجل تريد الاحتفاظ به. وثّق الخطأ أولاً. ثم ثبّت أحدث APK ناجح.
2. **الواجهة:** افتح الرئيسية، المحادثة، المحركات والإعدادات، وتأكد من وضوح العربية والشعار والتباين وعدم التداخل مع أشرطة النظام.
3. **اسم المساعد:** غيّر الاسم، أغلق التطبيق وأعد فتحه، وتأكد من حفظ الاسم.
4. **المحركات السحابية:** اختر OpenAI ثم Gemini ثم Claude. تأكد أن لكل واحد مفتاحه ونموذجه، ولا ترسل إلا بتوفر الحصة أو الرصيد. لا تصور المفاتيح.
5. **Ollama:** اختبر الاتصال بكمبيوتر LAN فقط بعد تشغيل نموذج محلي على الكمبيوتر. لا تفتح المنفذ للإنترنت العام.
6. **ذكاء الهاتف LiteRT-LM:** نزّل نموذج `.litertlm` قانونياً ومتوافقاً صغيراً ثم استورده من الإعدادات. افصل الإنترنت وأرسل سؤالاً عربياً. قس الزمن والحرارة والذاكرة. جرّب حذف الملف بعد تأكيد. انظر `docs/LOCAL_LM_SETUP_AR.md`.
7. **المحادثات:** فعّل حفظها اختيارياً. أرسل رسائل، أغلق التطبيق وافتحه، جرب التصدير إلى TXT والحذف النهائي، وتأكد أن المحركات لا تتبادل السجلات.
8. **الإملاء والنطق:** جرّب إدخال سؤال بالصوت بالعربية، وتأكد أنه يظهر بالنص للمراجعة قبل الإرسال. اختبر نطق الرد. قد تحتاج خدمة النظام إلى الإنترنت.
9. **المهام:** أضف مهمة، علّمها مكتملة، أعد تشغيل التطبيق، ثم احذفها بعد التأكيد.
10. **الملفات:** اختر TXT أو CSV من منتقي المستندات. تأكد أن المعاينة محدودة ومحلية. جرّب إغلاق المعاينة.
11. **الصور المحلية:** اختر صورة ثم فلتر أبيض وأسود أو سيبيا، واحفظ PNG وتأكد من فتحه في المعرض.
12. **توليد الصور السحابي:** فقط إذا كان مفتاح OpenAI API ورصيد مناسب متاحين، وافق على مربع التحذير وأرسل وصفاً قصيراً، ثم احفظ الصورة الناتجة. إذا لم يوجد رصيد، اكتفِ باختبار ظهور التأكيد، ولا تشحن الحساب لمجرد الفحص.
13. **الفيديو:** اختر صورة، اضغط «إنشاء فيديو 8 ثوانٍ»، ثم احفظ MP4. شغّله بمشغل الهاتف، تأكد من 9:16 ووجود زوم ناعم، وعدم وجود صوت.
14. **اختصارات الهاتف:** تأكد أن الضغط على لوحة الاتصال لا يجري مكالمة، وأن المشاركة لا ترسل تلقائياً، وأن كل فعل يظهر حوار موافقة.
15. **الخصوصية:** اترك جميع الأذونات الخاصة غير مطلوبة. جرّب العمل دون إنترنت مع الأدوات المحلية؛ لا تخلط بين النماذج المحلية والسحابية.

## 3. ما لا يصح ادعاء إنجازه
- لا توجد ضمانة أداء أو دقة للذكاء المحلي قبل اختبار ملف نموذج متوافق على الجهاز.
- لا يوجد توليد فيديو متحرك بالذكاء الاصطناعي مع شخصيات أو شفاه متزامنة؛ أداة MP4 الحالية تكبّر صورة واحدة بصمت.
- لا توجد أتمتة شاملة لتطبيقات الهاتف أو خدمة استماع دائم.
- لا يوجد تكامل تجاري آمن لخدمات API أو نظام حسابات/دفعات.
- لا توجد اختبارات أجهزة متعددة أو فحص أمن تجاري أو ترخيص نشر نهائي.

## فحص المفاتيح والمحركات في 0.10.4

1. من قائمة المحركات اختر OpenAI ثم افتح الإعدادات. اضغط «كيف آخذ المفتاح؟» وتحقق أن الصفحة الرسمية تفتح.
2. الصق المفتاح وانقر «حفظ المفتاح». بعد الحفظ يجب أن تصبح خانة الإدخال فارغة، وأن يظهر أن المفتاح محفوظ ومشفر.
3. أغلق التطبيق وأعد فتحه: تبقى حالة الحفظ، ولا يعرض التطبيق المفتاح المحفوظ مرة أخرى.
4. نفّذ اختبار اتصال OpenAI. النجاح في قراءة بيانات النموذج لا يثبت القدرة على إجراء محادثة مدفوعة؛ جرّب رسالة واحدة فقط إن كان عندك رصيد.
5. كرّر مع Gemini وClaude بمفاتيح مختلفة. تحقّق من أن مفتاح كل خدمة مستقل.
6. احذف مفتاح Gemini، وتأكد أن OpenAI بقي محفوظاً. حذف مفتاح الهاتف لا يلغيه في موقع Google.
7. اقرأ الدليل المدمج لتجربة الإملاء الصوتي وقراءة الرد؛ لا يوجد استماع خلفي.
8. لا تختبر الذكاء المحلي دون استيراد ملف نموذج متوافق وتجربة رد دون إنترنت.
