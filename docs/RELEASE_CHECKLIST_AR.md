# قائمة مراجعة الإصدار — Shbeeb One 0.11.0

هذه قائمة قبول لنسخة اختبار وليست شهادة إطلاق. نجح البناء الآلي المحلي، لكنه لا يثبت أداء نموذج الصور على الهاتف. لا يُعتمد الإصدار مستقراً قبل اختبار OPPO Find X5 ومراجعة الأمان والتراخيص.

## 1. تحقق المصدر والبناء

- [x] اجتياز `yarn typecheck`.
- [x] اجتياز `yarn translations:verify`؛ ملف العربية يحتوي 1317 نصاً ولا توجد قيم فارغة.
- [x] اجتياز `yarn test --runInBand` — 74 اختباراً.
- [x] اجتياز `yarn lint` بلا أخطاء؛ توجد تحذيرات ESLint في المصدر/الاعتمادات.
- [x] اجتياز `:app:testDebugUnitTest` و`:app:lintDebug` محلياً.
- [x] نجاح `:app:assembleRelease` بعد إضافة JNI ومحرك الصور.
- [x] احتواء APK المحلي على `assets/index.android.bundle` و`lib/arm64-v8a/libshbeeb_media.so`، واجتياز تحقق APK Signature Scheme v2.
- [x] فحص تغييرات المصدر للتأكد من عدم إدخال Firebase أو مفاتيح/أسرار توقيع.
- [ ] نجاح GitHub Actions على commit فرع التطوير وظهور artifact `shbeeb-one-android-standalone-package`.
- [ ] تنزيل artifact العام والتحقق من ZIP وAPK و`SHA256SUMS.txt` ومطابقة البصمة.
- [x] رقم الإصدار `0.11.0`، versionCode `18` ومعرّف الحزمة `com.shbeeb.ai`.

## 2. تثبيت الحزمة على الهاتف

1. نزّل الحزمة المستقلة من **GitHub → Actions → التشغيل الناجح → Artifacts**، ثم فك ZIP.
2. ثبّت `app-release.apk`. إذا ظهر تعارض توقيع مع نسخة سابقة، احفظ بياناتك أولاً؛ قد يلزم إزالة النسخة السابقة الموقعة بمفتاح مختلف.
3. افتح التطبيق دون Metro أو اتصال بالكمبيوتر. ظهور «Unable to load script» يعني غالباً تثبيت APK Debug بدلاً من Release أو غياب الحزمة في الملف المثبّت.
4. راجع اسم Shbeeb One، اتجاه العربية، التباين، أشرطة النظام والتنقل.
5. اختر العربية من إعدادات واجهة AnythingLLM المدمجة، وأعد فتح التطبيق إذا لم يتغير اتجاه التخطيط.

## 3. الاختبارات الوظيفية المطلوبة على الهاتف

| المجال | الاختبار | ملاحظة قبول |
| --- | --- | --- |
| المحادثة | تشغيل LiteRT-LM محلياً دون إنترنت ثم مزود سحابي اختياري | محرك `llama.rn` داخل AnythingLLM منفصل عن LiteRT-LM؛ لا تضع مفاتيح في صورة/تقرير |
| AnythingLLM | فتح مساحة عمل، وثيقة وPDF، ثم إغلاق التطبيق وإعادة فتحه | يجب أن يعمل Release دون Metro؛ يلزم اختبار الهاتف |
| العربية | تبديل اللغة إلى العربية والتنقل بين شاشات التطبيق المدمج | الترجمة الآلية مكتملة من ناحية المفاتيح فقط؛ يلزم تدقيق لغوي وRTL فعلي |
| الصوت | إدخال كلام عربي عبر Android ثم نطق الرد بـTTS | لا يوجد استماع دائم أو حوار حي ثنائي الاتجاه؛ خدمة النظام قد تحتاج الشبكة |
| الصور المحلية | اختيار/تنزيل نموذج SD 1.5 Q4 (نحو 1.57 GB)، توليد 512×512، إلغاء وحفظ PNG | بعد تنزيل النموذج افصل الإنترنت؛ سجّل الوقت والذاكرة والحرارة. المحرك CPU تجريبي |
| مشاركة النموذج | افتح الملف نفسه في التطبيق الآخر عبر منتقي Android | يجب على المستخدم منح إذن الوصول؛ لا يمكن لتطبيق قراءة مجلد بيانات تطبيق آخر مباشرة |
| الصور السحابية | اختياري مع مفتاح ورصيد مناسب وموافقة على تحذير التكلفة | مستقلة عن التوليد المحلي؛ لا حاجة للدفع لاختبار الصورة المحلية |
| الفيديو | إنشاء MP4 صامت من صورة وحفظه وتشغيله | أداة تحريك/تحرير صورة، وليست توليد فيديو diffusion من النص |
| التحكم بالهاتف | فتح لوحة اتصال/إعدادات/مشاركة بعد تأكيد المستخدم | لا يجري التطبيق مكالمة ولا يرسل المشاركة تلقائياً |
| الخصوصية | تجربة الأدوات المحلية دون اتصال ومراقبة الخدمات التي اختارها المستخدم | Telemetry/Firebase معطلان؛ يرسل تنزيل النموذج طلباً لمصدره العام فقط بعد الاختيار |

## 4. معايير النجاح والحدود

- ينجح قبول APK إذا أمكن تثبيته، فتح المكوّنين، واستخدام الأدوات دون تعطل أو إفشاء أسرار.
- لا تُعد ميزة الصور المحلية ناجحة على الجهاز حتى يتم توليد ملف فعلي على OPPO Find X5 وقياس الزمن والذاكرة والحرارة.
- لا يُدّعى أن SD 1.5 يفهم العربية كالنماذج الكبيرة؛ الإنجليزية أدق غالباً لهذا النموذج.
- لا يُدّعى أن Wan أو أي نموذج فيديو diffusion يعمل باحتراف على الهاتف؛ لا يُحمّل نموذج فيديو تلقائياً.
- لا تُعد الترجمة العربية مراجعة بشرية نهائية حتى تُراجع لغوياً وعلى الهاتف.
- نجاح CI وحده لا يجعل التطبيق مستقراً؛ التوقيع الحالي تجريبي، ويلزم اختبار الهاتف ومراجعة أمان قبل أي نشر تجاري.
