# دمج AnythingLLM Mobile داخل Shbeeb One

**التاريخ:** 17 نوفمبر 2026.
**المستودع العام:** [mustafashbeeb/Shbeeb-One-Android](https://github.com/mustafashbeeb/Shbeeb-One-Android).
**فرع التطوير:** `feature/on-device-media-generation`.
**النسخة:** 0.11.0 تجريبية، Android package `com.shbeeb.ai`، versionCode `18`.

## الحالة الحالية باختصار

نجح محلياً بناء APK Release مستقل بعد إدخال مصدر محرك الصور، واجهة JNI، وحزمة JavaScript داخل APK. كما نجحت اختبارات Android وLint وTypeScript وJest. لم يُختبر تشغيل نموذج الصور على OPPO Find X5 نفسه بعد، ولم تُرفع هذه التغييرات للفرع العام/Actions في هذه المرحلة؛ لذلك لا أصفها بأنها إصدار مقبول أو ثابت.

## ما الذي يعنيه الدمج

بقي تطبيق Android الأصلي بلغة Kotlin/Jetpack Compose نقطة التشغيل، وأضيفت تجربة AnythingLLM Mobile (React Native) كجزء مدمج يفتح من واجهة Shbeeb One. يحتوي التطبيق لذلك على مسارين للذكاء: شاشات Shbeeb الأصلية، وتجربة AnythingLLM ومساحات العمل والوثائق. لا يعني الدمج أن محرك AnythingLLM أصبح تلقائياً المحرك الأساسي لكل تبويبات Shbeeb.

تضم تجربة AnythingLLM مساحات العمل والمحادثات والوثائق وPDF والاسترجاع المعزز بالمستندات ومحرك `llama.rn` المحلي وفق المصدر المنقول. يستخدم Shbeeb الأصلي LiteRT-LM للمحادثة المحلية، إضافة إلى مزودات أخرى حسب الإعداد. لا يتشارك المحركان نموذجاً أو ذاكرة تلقائياً؛ توحيدهما في طبقة ذكاء واحدة ما زال عملاً غير منجز.

## الاسم واللغة العربية

اسم المنتج الظاهر والمستودع هو **Shbeeb One (شبيب ون)**. بقي اسم AnythingLLM في مواضع الإسناد أو عند الإشارة إلى خادم AnythingLLM الأصلي. بقي معرّف Android `com.shbeeb.ai` لتفادي كسر توافق التثبيت والبيانات.

أضيفت واجهة عربية أولية لتجربة React Native: **1317 نصاً** في ملف العربية، مع تفعيل RTL عند اختيار العربية. اجتاز القاموس تحقق المفاتيح والمتغيرات، ولا توجد قيم عربية فارغة في الملف. هذه ترجمة أولية مولّدة آلياً؛ تحتاج مراجعة لغوية وتجربة فعلية على الهاتف قبل اعتبارها نهائية. تغيير الاتجاه قد يحتاج إغلاق التطبيق وإعادة فتحه.

## الصور المحلية

أضيف محرك `stable-diffusion.cpp` المرخص MIT كمصدر فرعي، وربط Android عبر NDK وCMake وJNI لـ`arm64-v8a`. يتيح استوديو الصور اختيار ملف نموذج موجود أو تنزيل النموذج إلى مجلد يختاره المستخدم عبر Android SAF، مع تحقق من حجم الملف وبصمة SHA-256، ثم توليد PNG محلياً. عند مغادرة شاشة الصور، يُلغى التوليد النشط ويُحرر سياق المحرك لتقليل ضغط الذاكرة.

النموذج التجريبي المقترح هو SD 1.5 Q4 بحجم يقارب **1.57 GB**، وليس ضمن المستودع أو APK. الإعداد الحالي محافظ: 512×512 و20 خطوة وعلى CPU. نجاح البناء يثبت أن مسار التطبيق الأصلي يُترجم، لكنه لا يثبت أن النموذج يعمل أو أن السرعة والحرارة مقبولتان على هاتف المستخدم. يُتوقع أن يكون توليد الصور على CPU أبطأ من خدمة سحابية. يمكن اختيار الملف نفسه من التطبيق الآخر عبر منتقي الملفات إذا منحه المستخدم إذن الوصول؛ لا يستطيع Android السماح لتطبيق بالكتابة مباشرةً داخل مجلد بيانات تطبيق آخر.

## الفيديو والصوت والتحكم

- أداة الفيديو الحالية تنشئ/تحرك صورة إلى MP4 صامت؛ **ليست** توليد فيديو diffusion من وصف نصي. لم يُدمج مولد فيديو محلي موثوق لهاتف Snapdragon 888 وذاكرة 8GB.
- الصوت المتاح إدخال كلام عند الطلب عبر خدمة Android، ثم قراءة الرد بواسطة TTS. هذا ليس حواراً صوتياً مستمراً ثنائي الاتجاه.
- وظائف التحكم تفتح واجهات النظام أو التطبيقات المقصودة بعد تأكيد المستخدم. لا يوجد تحكم شامل أو خفي بكل التطبيقات، ولا استماع دائم.

## الخصوصية والتراخيص

لم تُضف مفاتيح API أو أسرار توقيع أو إعداد Firebase إلى المستودع. Telemetry وFirebase analytics/crash reporting معطلان في هذا البناء. تنزيل النموذج يتطلب اختيار المستخدم، ويرسل طلبات إلى مصدر النموذج العام؛ أما توليد الصور بعد التنزيل فيعمل محلياً ولا يرسل وصف الصورة إلى مزود سحابي. مزود سحابي يختاره المستخدم يرسل الطلبات إلى ذلك المزود.

يتيح إعداد Android أيضاً HTTP غير المشفر لتوافق خادم محلي يختاره المستخدم مثل Ollama؛ هذا لا يرسل بيانات بحد ذاته، لكن ينبغي استخدامه على شبكة موثوقة فقط ويفضّل HTTPS للخوادم البعيدة. لا يوجد إذن موقع في Manifest.

المشروع المركب خاضع لـGPL-3.0-or-later، مع الالتزام بإشعارات وتراخيص AnythingLLM و`stable-diffusion.cpp` وGGML ومكوّنات الاعتماد. ترخيص أوزان SD 1.5 (CreativeML OpenRAIL-M) منفصل عن ترخيص الشفرة. التفاصيل في [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) وملفات التراخيص الأصلية.

## نتائج التحقق المحلي

- `yarn typecheck`: ناجح.
- `yarn translations:verify`: ناجح؛ القاموس العربي 1317/1317 بلا مفاتيح فارغة.
- `yarn test --runInBand`: **74 اختباراً ناجحاً**.
- `yarn lint`: ناجح بلا أخطاء؛ توجد تحذيرات ESLint قائمة في المصدر/الاعتمادات.
- `:app:testDebugUnitTest` و`:app:lintDebug`: ناجحان.
- `:app:assembleRelease`: ناجح. فُحص APK واحتوى `assets/index.android.bundle` و`lib/arm64-v8a/libshbeeb_media.so`، ونجح التحقق من توقيعه التجريبي.
- لم يتم بعد تشغيل التطبيق أو توليد صورة فعلياً على OPPO Find X5، ولم يُفحص GitHub Actions/Artifact لهذا الفرع بعد.

## الخطوات التالية

1. رفع الفرع وتشغيل CI العام، ثم تنزيل artifact والتحقق من APK وZIP وSHA-256.
2. تثبيت حزمة Release على OPPO Find X5. إذا تعارض التوقيع مع نسخة سابقة، احفظ البيانات أولاً ثم أزل النسخة القديمة عند الحاجة.
3. تنزيل النموذج إلى المجلد الذي يختاره المستخدم، فصل الإنترنت، ثم تجربة التوليد والإلغاء والحفظ وقياس الوقت والذاكرة والحرارة.
4. مراجعة ترجمة العربية واتجاه RTL على الهاتف.
5. إبقاء ميزات الفيديو diffusion، والمحادثة الصوتية الحية، وتوحيد محرك الذكاء بين التبويبات موسومة كأعمال لاحقة حتى تنفيذها واختبارها فعلياً.
