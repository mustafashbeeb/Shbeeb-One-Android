# خارطة طريق Shbeeb One — الحالة حتى 17 نوفمبر 2026

**المنتج:** Shbeeb One (شبيب ون)، تطبيق Android عربي.
**المستودع:** [mustafashbeeb/Shbeeb-One-Android](https://github.com/mustafashbeeb/Shbeeb-One-Android).
**الفرع:** `feature/on-device-media-generation`.
**الإصدار الجاري للاختبار:** 0.12.0، versionCode `19`، Android package `com.shbeeb.ai`.

## الرؤية

مساعد شخصي عربي عملي يبدأ بالمحادثة، ويجمع الذكاء المحلي والسحابي الاختياري، والصوت عند الطلب، والاستوديو المحلي، وأدوات الهاتف الآمنة. لا يُرسل أي طلب سحابي قبل موافقة المستخدم، ولا تُعرض ميزة غير مثبتة كما لو أنها تعمل.

## الخطوات التالية

1. تثبيت APK 0.12.0 على OPPO Find X5، والتأكد من التحديث والواجهة العربية وفتح محادثة LiteRT فعلية دون إنترنت. قياس الذاكرة والزمن والحرارة.
2. إذا رغبت باستعادة تبويب AnythingLLM، التقط سجل Android Studio Logcat عند فتحه، وابحث عن `ShbeebAnythingActivity` أو `Shbeeb One React Native global error`. افحصه واحذف أي بيانات خاصة قبل مشاركته.
3. بعد إصلاح AnythingLLM واختباره على الجهاز، أعد إتاحة دخوله واختبر مساحة العمل والوثائق وPDF والمشاركة الفعلية لملف GGUF. يبقى GGUF مختلفاً عن LiteRT `.litertlm`.
4. اختبر توليد صورة محلياً بعد تنزيل SD 1.5، ثم الفيديو الصامت من صورة والصوت بالعربية. سجّل نقاط الفشل بدلاً من افتراض النجاح.
5. بعد اكتمال الفحص الآلي، ادفع فرع التطوير وتحقق من GitHub Actions وartifact/ZIP. يبقى أي نشر عام مشروطاً بقبول الجهاز واستبدال توقيع Debug بمفتاح إنتاج محفوظ خارج Git.

## المخاطر والقيود

ذاكرة OPPO Find X5 (8 GB) مشتركة مع Android والتطبيقات. يحتاج تشغيل LiteRT نسخة ملف إضافية، وقد يكون Stable Diffusion على CPU بطيئاً أو يسبب سخونة. جودة SD 1.5 في العربية أقل عادةً من الإنجليزية. قد تكون APIs السحابية مدفوعة، وطلباتها تحمل سياقاً حديثاً بعد موافقة المستخدم. HTTP المحلي لـOllama ينبغي أن يبقى ضمن شبكة موثوقة. لا يوجد اختبار هاتف أو قياس أداء فعلي لهذا الإصدار.

## قواعد العمل

كل ميزة تمر بمراحل: تنفيذ → تحقق مصدر → بناء → اختبار على هاتف → توثيق → قبول. التوثيق والواجهة للمستخدم بالعربية. لا أسرار في المستودع، ولا ننسب وظيفة إلى التطبيق لمجرد وجود زر أو نموذج أولي. تبقى الميزات غير المختبرة معلّمة كتجريبية.
