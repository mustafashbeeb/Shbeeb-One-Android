# خارطة طريق Shbeeb One — الحالة حتى 17 نوفمبر 2026

**المنتج:** Shbeeb One (شبيب ون) — تطبيق Android عربي.
**المستودع العام:** [mustafashbeeb/Shbeeb-One-Android](https://github.com/mustafashbeeb/Shbeeb-One-Android).
**الترخيص الأساسي:** GPL-3.0-or-later، مع الالتزام بتراخيص المكوّنات والأوزان منفردة.
**النسخة قيد العمل:** 0.11.0 تجريبية؛ لا تُعد مستقرة قبل اختبار الهاتف.

## الرؤية

مساعد شخصي عربي عملي يجمع المحادثة، المعرفة والملفات، الصوت عند الطلب، الصور المحلية، ومهام الهاتف الآمنة. يستخدم المعالجة المحلية حيثما كان ذلك عملياً، مع مزودات سحابية اختيارية واضحة التكلفة والخصوصية. لا يعد بأداء يفوق حدود الجهاز ولا ينفذ إجراءات الهاتف خفية.

## خطة العمل ومعايير الانتقال

**أولاً — إصدار اختبار 0.11.0.** أضيفت مكتبة GGUF المشتركة لتنزيل النماذج مباشرة إلى مجلد المستخدم أو ربط ملف موجود. يجب الآن إعادة اختبارات Android وLint وبناء Release ثم دفع الفرع للتحقق من APK وZIP عبر CI.

**ثانياً — اختبار الهاتف.** ثبّت APK المستقل على OPPO Find X5، واختبر المحادثة والوثائق والصوت، واختر/نزّل نموذج الصور، وافصل الإنترنت، ثم ولّد صورة وألغها واحفظ PNG. سجّل وقت التوليد والذاكرة والحرارة. فشل الأداء يعني خفض الإعدادات أو تأجيل الميزة، لا الادعاء بنجاحها.

**ثالثاً — توحيد الذكاء عبر التبويبات.** يتطلب تصميم واجهة AI موحدة (محرك محلي أو سحابي أو خادم يختاره المستخدم) وربطها بالوظائف النصية مع احترام موافقة المستخدم. تحتاج GGUF وLiteRT-LM توافقاً منفصلاً أو اختيار محرك واحد. هذا التوحيد الشامل لم يُنفذ بعد.

**رابعاً — تحسين الصوت والتحكم.** اختبر STT/TTS العربية، ثم صمم تجربة صوتية تفاعلية عند الطلب دون ميكروفون دائم. أدوات الهاتف تبدأ بإجراءات Intent آمنة تعرض الهدف والتأكيد قبل أي أثر خارجي.

**خامساً — توليد الوسائط.** طوّر الصور المحلية بحسب قياسات الهاتف. لا تضف أوزان النموذج إلى APK. توليد الفيديو النصي محلياً مؤجل؛ ميزة MP4 الحالية تحريك لصورة وليست فيديو diffusion.

**سادساً — الإصدار العام/التجاري.** راجع GPL ومكوّنات MIT وتراخيص الأوزان، ونفذ اختباراً أمنياً وعلى أجهزة متعددة، ثم استخدم مفتاح توقيع ثابتاً محفوظاً خارج GitHub. توقيع Debug الحالي للتجربة فقط.

## المخاطر والقيود

ذاكرة الهاتف 8GB مشتركة مع Android؛ الذاكرة الافتراضية ليست بديلاً عن RAM. محرك الصور الحالي CPU وقد يكون بطيئاً أو يرفع الحرارة. SD 1.5 يفهم الإنجليزية أفضل من العربية. فيديو Wan منخفض الدقة يتطلب ملفات كبيرة وذاكرة تشغيل مرتفعة، ولا يوجد benchmark يثبت ملاءمته لـSnapdragon 888. مزودات API قد تكون مدفوعة؛ وفتح Ollama عبر LAN يتطلب إعداداً آمناً. حدود Android تمنع الوعد بالتحكم المطلق في التطبيقات.
